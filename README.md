One letter for my day: **X** — exhausted (and exasperated). The word behind the letter is the whole day in one character: a battery run flat, a day crossed out. X is not the obvious initial for that word — E would be — it is the punchier one, and its shape is the picture itself.

## Run it

```sh
node main.ts
```

Writes exactly one character, `X`, to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
